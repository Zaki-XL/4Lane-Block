# 4Lane Block (4レーン・ブロックソートパズル)

## 概要

**4Lane Block** は、4つのレーンと3色のブロックを使用した思考型ソートパズルゲームです。
各レーンにランダムに積まれた3色のブロックを、レーンの一番上から1つずつ移動させ、最終的に各レーンを1つの色で統一（全3レーン）して完成させることを目指します。

```mermaid
        G3["Lane 3<br/>[緑, 緑, 緑]"]
        G4["Lane 4<br/>(空レーン)"]
    end

    初期状態 -->|ブロック移動| ゴール状態
```

## 基本ルール

1. **4つのレーン**: すべてのレーンに共通の高さ制限（$H$）があります。
2. **3色のブロック**: 各色のブロック数はそれぞれ1レーン分の高さ制限（$H$ 個）と同数で、合計 $3H$ 個存在します。
3. **初期配置**: ゲーム開始時に、すべてのブロックが4つのレーンへランダムに配置されます。
4. **移動操作**: プレイヤーは任意のレーンの**最上部にあるブロック**を持ち上げ、**他のレーンの最上部**へ移動させることができます。
5. **高さ制限**: 各レーンの高さ制限（$H$）を超える移動はできません。
6. **ゴール**: 3つのレーンにそれぞれ同一色のブロックを上限まで積み上げ、3つの単色レーンを完成させるとクリアです（残り1レーンは空になります）。

## 主な特徴・設計方針

- **Webブラウザ完全対応（無料公開）**: GitHub Pages 等を活用し、サーバー費用0円でPC・スマートフォンから即座にプレイ可能。
- **操作API抽象化**: コアロジックをUI・デバイスから分離し、API経由で「クリック/タップ」「ドラッグ＆ドロップ」「キーボード操作」を統合制御。
- **ソルト（シード）による盤面再現**: ゲーム開始時に発行されるソルト（英数字）を入力することで、いつでも同一の盤面を再現・共有可能。
