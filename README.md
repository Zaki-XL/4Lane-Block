# 4Lane Block (4レーン・ブロックソートパズル)

## 概要

**4Lane Block** は、4つのレーンと3色のブロックを使用した思考型ソートパズルゲームです。
各レーンにランダムに積まれた3色のブロックを、レーンの一番上から1つずつ移動させ、最終的に各レーンを1つの色で統一（全3レーン）して完成させることを目指します。


## 基本ルール

1. **4つのレーン**: すべてのレーンに共通の高さ制限（デフォルト: $H = 10$、可変設定: 3〜15）があります。
2. **3色のブロック**: 各色のブロック数はそれぞれ1レーン分の高さ制限（$H$ 個）と同数で、合計 $3H$ 個存在します（デフォルト10段の場合: 計30個）。
3. **初期配置**: ゲーム開始時に、すべてのブロックが4つのレーンへランダムに配置されます。
4. **移動操作**: プレイヤーは任意のレーンの**最上部にあるブロック**を持ち上げ、**他のレーンの最上部**へ移動させることができます。
5. **高さ制限**: 各レーンの高さ制限（$H$）を超える移動はできません。
6. **ゴール**: 3つのレーンにそれぞれ同一色のブロックを上限まで積み上げ、3つの単色レーンを完成させるとクリアです（残り1レーンは空になります）。

## 主な特徴・設計方針

- **Webブラウザ完全対応（無料公開）**: GitHub Pages 等を活用し、サーバー費用0円でPC・スマートフォンから即座にプレイ可能。
- **1画面フィット・動的スケーリング**: ブラウザの縦幅に合わせてブロックの高さを自動算出し、10段や15段でも縦スクロール不要で常に1画面に美しく収まります。
- **難読化ソルトによる盤面再現**: 高さ情報や乱数シードを可逆アフィン暗号で難読化し、外部から平文の手がかり（`H10` 等）が一切読み取れない8桁英数字（例: `K8X2-9M4B`）として発行・復元。
- **リアルタイム・カウントアップ計測**: ゲーム開始からクリアまでのタイムを高精度に計測・表示し、クリア時に手数・タイム・ソルトを記録。
- **操作API抽象化**: コアロジックをUI・デバイスから分離し、API経由で「クリック/タップ」「ドラッグ＆ドロップ」「キーボード操作」を統合制御。

## 遊び方・起動方法

### ローカル環境での起動
Windows 環境では、プロジェクト直下の `start.bat` をダブルクリックするだけで、ローカルHTTPサーバーが立ち上がり、ブラウザが自動的に開きます。

```cmd
start.bat
```

またはターミナルから以下のコマンドを実行してください：
```powershell
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### 操作方法
- **クリック / タップ**: レーンをクリックして最上部ブロックを持ち上げ、移動先レーンをクリックして配置。
- **ドラッグ＆ドロップ**: ブロックを直接掴んで目的のレーンへドロップ。
- **キーボード**:
  - `[1]` 〜 `[4]` キー: レーン直接指定
  - `[←]` / `[→]` キー: レーンのフォーカス移動
  - `[Enter]` / `[Space]` キー: 持ち上げ / 配置の決定
  - `[Esc]` キー: 持ち上げキャンセル
